## 🚀 How to Run the Website

### Option 1: Double-Click (Zero Installation Required!)
Simply double-click `index.html` in your file explorer. It will open in Google Chrome, Microsoft Edge, Brave, or Safari immediately.

### Option 2: Run a Local Development Server (Optional)
If you have Python or Node installed:
```bash
# Using Python
python -m http.server 3000

# Using Node (npx)
npx serve .
```
Then visit `http://localhost:3000`.

## 📸 How to Change Your Photo

You have two easy ways to use your actual photo:
1. **In the Browser (Instant)**: Open `index.html`, hover over the Polaroid photo, and click **"Change Photo"**. Pick any picture from your device. It will immediately update and stay saved!
2. **In the Code (Permanent)**:
   - Place your photo inside `assets/images/` (e.g. `assets/images/my-photo.jpg`).
   - Open `index.html` in any text editor (like Notepad or VS Code).
   - Find `<img src="assets/images/noufal-avatar.svg" id="creatorAvatarImg"` and change the `src` to `assets/images/my-photo.jpg`.
